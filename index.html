Integrasi Google Sheet Real-Time

Masukkan URL WebApp Google Apps Script Anda agar data pengunjung dikirimkan secara langsung ke Google Sheet perpustakaan.

Kode Apps Script Google Sheet (doPost):

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var d = JSON.parse(e.postData.contents);
  sheet.appendRow([new Date(), d.name, d.role, d.idNum, d.purpose]);
  return ContentService.createTextOutput("OK");
}
